# Clenzit Franchise Intelligence

Location intelligence for Clenzit franchise expansion. The application uses
Google Geocoding and Places data for live, location-specific business context.
Meta audience estimates remain explicitly unavailable until the optional Meta
Marketing API configuration is supplied.

## Required environment variable

`GOOGLE_MAPS_API_KEY` must be configured on the hosting platform. Enable both
Google Geocoding API and Places API (New) for that key.

See `.env.example` for optional Meta Marketing API variables.
